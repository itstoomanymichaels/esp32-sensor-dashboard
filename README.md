# ESP32 Sensor Dashboard

A Wi-Fi connected sensor dashboard built on the ESP32. Reads temperature 
and humidity from a DHT22 sensor, displays live data on an SSD1306 OLED, 
and publishes readings over Wi-Fi via MQTT.

Built in C++ using PlatformIO, Arduino framework, and FreeRTOS.

## Hardware
- ESP32 DevKitC
- DHT22 temperature/humidity sensor
- SSD1306 128x64 OLED display
- Breadboard + jumper wires
